OST, Rapperswil-Jona, Switzerland

Presented with Claudio Neto.

## About the workshop

This hands-on workshop showed how to add continuous integration checks to Nix configurations. Participants built automated pipelines to test and build configurations, lint code, and catch configuration errors on each change.
