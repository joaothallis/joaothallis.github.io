## About the speaker

João Thallis is self-taught. He decided to learn programming as a teenager to create games, and learned Elixir to complete a technical challenge for a position at Stone Pagamentos, then the country's fifth-largest acquiring company. After a two-year internship at Stone, he was a software developer at Conta Stone, a digital payments account built with Elixir, his favorite programming language.

## About the workshop

This workshop covers building and configuring an application from scratch with Elixir, a functional programming language created in Brazil. It includes a practical look at continuous integration setup, tools that improve code quality and help prevent errors, and deploying the application to production.

### Topics

- Installing the required tools
- Starting a project
- Tools for improving code quality
- What continuous integration is
- Adding these tools to continuous integration
- Deploying the application
